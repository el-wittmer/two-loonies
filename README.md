# budget-international
Currency conversion and money bucketing for international partnerships. The live website is hosted at [https://el-wittmer.github.io/two-loonies](https://el-wittmer.github.io/two-loonies), though guests will not be able to authenticate. I am working on a live demo for unauthorized users to show the full functionality.

## AI statement
Agentic AI has not and will not be used in the development of this project. Google (AI Mode) has been used as a resource for debugging.
